# 页面截图来源

这 7 张截图于 2026-09-18 使用当前版本的真实页面、样式和交互重新拍摄，由 Edge / Playwright 在独立演示数据库中生成。没有绘制替代界面或修改页面 DOM 伪造功能。

- supplier-current.png：手机端首笔订单，含收货信息、单号识别和视频保存结果。
