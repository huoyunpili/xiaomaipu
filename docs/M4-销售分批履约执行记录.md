# M4 销售分批履约

日期：2026-09-08。

订单发货页增加“本次发货数量”，默认填入当前已备货数量，并列出实际备货货况及发货顺序。可以先发已有库存，剩余缺口继续采购、收货和备货，再次发出。

每次发货独立保存数量、交付方式、物流公司、运单号、出库成本和履约费用。拆分一条备货记录时，已发出的部分形成独立出库分配，未发部分继续锁定。退货数量按对应已出库分配限制。

部分发货时订单显示“部分已发货”，可继续补货、备货和发货。全部发出后，若任一批快递或闲鱼交易仍需确认，订单保持已发货；整单确认履约后才标记全部批次完成。全部为非闲鱼当面交付或自提时，最后一批交付后直接履约完成。已实现利润仍要求整单履约完成且实际净收款等于应收。

## 一致性

- 发货沿用订单锁、库存余额锁和幂等提交，批次记录、库存扣减、分配拆分、成本、费用与状态在同一事务内写入。
- 本次数量不得超过已锁库存。缺货时必须明确本次数量，旧服务默认整单发货的数量校验保持兼容。
- 部分发货后补锁库存不会把状态退回未发货；关联采购和到货备货继续可用。
- 已发出部分不能通过整单取消回补库存，需走退货流程；仅取消剩余未发数量尚未实现。
- 旧订单原物流字段保留；没有新批次记录的历史订单继续显示原交付信息，不编造历史批次。
