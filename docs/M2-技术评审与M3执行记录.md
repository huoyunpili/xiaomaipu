## 工程决策

- 本机已有 Python 3.12；本地允许 3.12，生产镜像与 CI 使用 3.13。使用同一 uv.lock，数据库始终为 PostgreSQL 17，不以 SQLite 代替事务测试。
- M3 使用小型自托管样式，无 CDN；Bootstrap、htmx 和图表依赖在对应复杂页面需要时加入。
- 普通业务管理员使用 `role=ADMIN`，操作员使用 `role=OPERATOR`；不开放绕过服务层的 Django 通用后台。
- 店铺更新服务同时执行权限、乐观版本检查、事务幂等、审计与 Outbox 写入。Outbox 本阶段只存储，不启动业务事件消费；M4 增加处理器与可靠重试后再启用。
- 日志采用允许字段列表，不打印自由文本、原始异常内容、请求参数或凭据；错误页面返回参考编号。
- PostgreSQL 与 Redis 使用本项目独立 Compose 名称与卷，仅向本机绑定开发端口。
- 初始化命令不创建默认密码，不覆盖已有店名或渠道配置。
