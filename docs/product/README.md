# 产品介绍页

对外分发文件：`docs/鱼管家产品介绍.html`。图片、样式和脚本均内嵌，可离线打开，也可作为静态网页部署。外部下载、仓库和反馈链接需要联网。

内容覆盖产品定位、五大亮点、订单流程示例、两种安装路径与功能配置。页面金额及截图订单均为演示数据，截图来自当前系统的隔离测试环境，不改动真实经营库。

修改 `docs/product/index.html` 后，在项目根目录执行：

```powershell
python scripts/build_product_page.py
```

构建脚本复用 `app/static/tokens.css` 和 `docs/product/images/*-current.png`。这些截图采用 3 倍设备像素原生渲染：桌面图至少 3504 × 1104，手机长图 1260 × 4245。原有 README 的真实截图不被演示截图替换。原始模板通过相对路径使用截图，最终交付使用构建后的文件。

当前验证：Edge 实际渲染，1365 / 390 / 320 像素宽度无页面横向溢出；内嵌图片、锚点、截图弹窗与 Esc 关闭、路径切换、命令复制均通过。介绍页没有向真实平台提交发货或上传视频。
