## 本轮脚本变更

- 发行备份用共享的只读 Python 摘要实现比较源库与恢复库，兼容升级前镜像已有的 psycopg 依赖，不要求旧镜像含新增管理命令。
- 新清单保存内容摘要；Restore 在执行迁移之前比对恢复内容，并在覆盖当前数据前检查备份附件哈希。
- Upgrade 对已有但停止运行的数据库也先备份，并更新配置中的镜像与发行版本。
- 访问日志只包含状态码和耗时。
