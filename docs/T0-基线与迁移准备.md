## 只读诊断

新增 `app/common/reconciliation.py`、管理命令 `reconcile_business_data` 和 `tests/test_reconciliation.py`。

```powershell
.\.venv\Scripts\python.exe manage.py reconcile_business_data --check
```

管理命令用 PostgreSQL REPEATABLE READ、READ ONLY 事务读取一致快照，比较销售收退款与 MoneyEntry、采购付款/退款与 PurchaseEvent、采购收退数量与 PurchaseReceipt、库存余额与实物组汇总。输出金额/数量、差额 UUID 及缺口计数；不输出客户信息、外部订单号或密钥。有差额时 --check 非零退出，不执行修复。缺失发运时间、直发到货及库龄等作为迁移缺口，不当成现金差额。

当前库检查无差额，检查范围内业务总额及库存为 0。限制：未覆盖每条库存流水、费用/利润、售后分配及附件引用；T1/T2 新模型落地后须扩展核对项，不宣称完整审计。

隔离样例：部分采购付款/收到能正确对账；人为制造现金/库存缓存偏差能发现且不修改；命令差异退出保持只读。原有采购测试期望“关闭剩余后在途为零”属于旧规则，T1 必须修改业务及相应测试，不能以现有测试通过认定符合新 PRD。
