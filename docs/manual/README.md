# 使用与配置手册

维护源文件：`docs/manual/index.html`。

对外阅读文件：`docs/小卖铺使用与配置手册.html`，样式和高清演示截图内嵌，可离线打开，支持目录、复制命令和打印。

构建：在项目根目录执行 `python scripts/build_manual.py`。截图引用 `docs/product/images` 中的演示素材，不包含真实客户资料或凭据。

编写依据为 2026-09-18 当前工作区，不等于公开 main 的功能全集。API 开通章节区分公开可确认的入口和需提供方确认的账号资格；未虚构套餐价格、审核通过承诺或回调地址。本手册编写不执行真实平台注册、付费、发货或恢复数据。

更新时核对：实际模板按钮、配置文件加载方式、容器环境变量、管理脚本参数、平台最新接入说明及公开版本差异。源码方式 backup_local 与发行脚本 Backup/Restore 是不同流程，不应互换。
