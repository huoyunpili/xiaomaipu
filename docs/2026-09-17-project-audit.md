# 2026-09-17 项目回归与边界检查

## 本轮修复

1. 供货商提交单号时锁定输入框、公司选择和按钮；收到响应后显示服务端实际保存的值，避免提交中修改导致显示与实际请求不一致。
2. 快递单号在服务端统一去除首尾空格并转大写，避免小写自动识别后提交格式不一致，以及大小写不同造成重复提交冲突。
3. 保存视频前重新读取链接撤销、到期和店铺启用状态。上传期间被停用的链接不能继续保存视频，失败文件会清理。
4. 发货结果回查按最近检查时间轮转，避免超过 20 条待确认记录时，后续记录长期得不到处理。回查不重新提交发货。
5. 历史清单区分正常发货后的状态变化与退款等风险变化。正常发货不再提示“停止发货”；退款风险仍保留该提醒。
