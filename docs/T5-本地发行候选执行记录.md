# T5 本地发行候选执行记录

## 当前结论

2026-09-14 已形成 0.5.0 RC1 本地运行骨架。它使用 Docker Compose、Gunicorn、Caddy、Celery Worker/Beat、PostgreSQL 和 Redis；浏览器只负责访问，后台服务独立运行。经营目录与源码分离，默认位于 %LOCALAPPDATA%/XianyuSeller。

T5 仍处于进行中。T5-01、T5-02、T5-06 已完成；T5-04 的手动备份、升级与恢复已通过，但 Windows 定时任务和跨日漏备尚未实测；T5-03 的真实手机与 T5-05 的全新电脑无缓存安装尚未执行。

## 已实现

- 本地发行设置强制随机密钥、私有数据库密码、显式允许主机并保持 DEBUG=False。
- 本地 Compose 仅映射 Caddy Web 端口；数据库与 Redis 仅加入内部网络。
- Python、PostgreSQL、Redis、Caddy 镜像固定版本和内容摘要；Python 依赖由 uv.lock 固定。
- 统一脚本支持 Install、Start、Stop、Restart、Status、Configure、Backup、Restore、Upgrade 和 Validate。
- 第一次打开浏览器时由使用者自行创建管理员用户名和密码；已有管理员后创建入口自动关闭。
- 命令行 init_local_admin 仅作为离线救援入口；正常安装不再要求用户进入终端创建账号。
- 第一次打开浏览器时由使用者自行创建用户名和密码；已有管理员后初始化入口自动关闭。旧开发环境中尚未登录的 dev-owner 会被安全认领和改名，账号主键及既有业务关联保持不变。
- 启动幂等执行迁移与 bootstrap；超过备份周期时在下一次启动补备。
- 可按数据目录注册或移除当前 Windows 用户每天 03:00 的独立备份任务。
- 工作台显示发行版本、最近备份时间及独立恢复是否通过。
- 打包脚本只从干净 Git 提交打包，并拒绝密钥、经营目录、日志和备份路径。
