# 本地统一查验说明 · 0.3.0

2026-09-11 更新：已增加 0.4.0 闲管家只读同步，最新步骤和发布边界见 [API 接入与发布查验](API接入与发布查验-0.4.0.md)。本文保留原经营功能查验步骤，旧版“未接入 API”描述以新文档为准。

本机地址：http://127.0.0.1:8765 ，原账号继续使用。按以下顺序集中查验即可，不需要逐阶段确认。

## 1. 货盘

- 新增商品时填写名称、货况、成色、库存数量和单件进货成本。货况与成色自由描述，成本没有单独的采购运费输入。
- 同商品不同实物情况分组录入；开单时核对实际货物，不会自动换成其他货况。
- 临时没有货可填 0 建档；调整库存保留盘点原因和流水。

## 2. 自有库存销售

- 从货盘或订单页开单，选择渠道和客户。已有客户可直接关联档案，新客户可先在“客户”建档。
- 确认订单锁库存；可以填写本次数量分批发货，每批物流、成本、费用和货况单独保留。
- 部分发货后可“关闭剩余未发数量”，核对本次应收减免；已收款不会自动退回，实际退款另外登记。
- 分次收款、退款、费用、退货待检/验收按原流程处理。履约完成且净收款与应收一致才确认利润。

## 3. 采购与直发

- 建供应商、记录报价，直接补货采购或从缺货订单创建关联采购。
- 自有库存采购分次收货，按实际货况入库；到货后可核对货况并为关联订单备货。
- 从缺货订单创建采购时可选“供应商直接发给买家”；确认下单后填写实际直发数量、货况、运单与取证说明。
- 直发只更新销售履约和采购成本，不变动自有库存。直发商品退到本店时先进入待检，验收后可入库。
- 采购付款、供应商退款、关闭未收数量与退回供应商分别记录，不把采购付款重复计入销售费用。

## 4. 客户与取证

- 客户支持称呼、联系方式、标签、备注、风险事实和后续处理提醒。
- 客户仍有交易、未核对完款项或待检售后时延后拉黑提醒，不自动拉黑或取消交易。
- 订单页可上传一段 MP4/WebM 视频（250 MB 内），播放、下载原文件；替换后保留历史版本。
- 二维码指向需登录的订单上传页。localhost 无法让其他手机访问；局域网或实际域名配好后才能跨设备扫码。

## 5. 表格导入

- 支持 CSV 和 XLSX，每次 10000 行以内、10 MB 以内；下载模板或在上传时调整列名对应关系。
- 渠道代码见导入页，商品编码见货盘详情。渠道订单号建议在 Excel 中按文本保存。
- 先预览再确认，后台逐行处理。错误行不阻止正确行，可下载错误清单。
- 重复文件返回已有任务；同一渠道订单号已存在时跳过，保留手工数据。
- 导入生成草稿供核对，不把表格状态或金额猜成已发货、已到账。闲管家专属导出字段及真实接口联调待双方配合。

## 6. 工作台、报表与风险

- 工作台显示订单、采购、退货待检、未留证、客户提醒、待退款核对及导入异常。
- 报表支持按订单创建日期、渠道筛选，分别汇总收款、退款、出库成本和已实现利润。
- 库存风险显示 7/30 天销量、趋势与阶段参考、可售天数、可售库存成本和预计降价损失。
- 市场参考价保留来源与日期，超过 30 天标记过期，不参与损失估算。核对过的事件进入未来 30 天提醒。
- 管理员可配置、启用或停用公开 RSS/Atom 源，每日任务读取并保留原文。标题匹配只是提示，事件影响需核对，不自动改价或下架。
- 店铺设置支持新增、自定义和停用渠道。

## 7. 本地交付边界

本版为本地手工/表格经营路径的统一查验版，不等同于已完成生产发布和真实业务灰度。

- 当前一张销售单对应一种商品，一张采购单对应一种商品及可选的一条销售明细，可分批履约。
- 直发售后当前支持货物退到本店验收；买家直接退给供应商的三方对账需后续结合实际流程细化。
- 客户不按同名或联系方式自动合并，避免串档；货况照片、多商品单据及高级会计账务未加入本版。
- 外部业务 API 连接没有自动重试，也未发送外部消息。市场源未配置时保持手工记录。
- 云端部署、真实接口联调、跨设备网络配置、正式数据导入与连续真实业务灰度仍需配合，不计为已验证。
